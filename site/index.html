How it’s checked

Each extension runs on a JVM harness, no phone. It loads popular, opens a manga and its chapter list, loads the newest chapter, then downloads and decodes two pages through the extension’s own client. Anything that fails gets one retry before it counts.

Partly working means you can still read, but something else (search, latest updates) fails. Might be broken means the site turned our checker away (Cloudflare, a 403, rate limiting), so it could be the site blocking automated checks or the extension itself. The tag says which. The app gets past most Cloudflare checks, so check there. Can’t test means we couldn’t get a result at all, like a self-hosted source or one that needs an account.

Not checked yet means today’s run hasn’t reached it; the last result is shown instead. Not supported means the extension still uses the older 1.4 extension API, which this checker doesn’t run.

Notes are things worth knowing that don’t stop reading, like a source repeating titles in its lists or only some titles opening. Before an extension counts as not working, up to three titles get a try, and every failure is checked once more at the end of the run.

Some of the checks (page 2 of lists, placeholder images) come from vetleledaal’s keiyoushi-status.

The small bars on each row are the last two weeks of runs, newest on the right. This runs off main, so it can be ahead of what’s published. Not affiliated with keiyoushi.
